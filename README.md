# kakeibo

家族で使うためのブラウザ家計簿アプリです。取引一覧、直接入力、月別ダッシュボード、CSV 取込、カテゴリマッピングを Web でまとめて扱います。

- 本番: https://kakeibo-mu-two.vercel.app
- モバイル版リポジトリ: https://github.com/hiyamuuugh/kakeibo-app

## セットアップ

```bash
npm install
copy .env.example .env
npm run db:seed
```

`.env` では少なくとも次を設定します。

- `DATABASE_URL`: Neon / PostgreSQL 接続先
- `APP_PASSWORD`: 家族共通のログインパスワード
- `APP_SESSION_SECRET`: セッション署名用の長いランダム文字列
- `GOOGLE_VISION_API_KEY`: レシート OCR を使う場合のみ

## デプロイ関連

`master` への反映で Vercel がデプロイされます。アプリはブラウザ利用前提で、iOS アプリ配布は行いません。

### 身内のみアクセス

認証はアプリ内ログイン画面で行います。未ログイン状態では画面と API の両方を `middleware` でブロックします。

本番で必要な環境変数:

- `APP_PASSWORD`
- `APP_SESSION_SECRET`
- `DATABASE_URL`
- `GOOGLE_VISION_API_KEY`（OCR を使う場合）

Vercel の Environment Variables に同じ値を設定してください。

### PWA

このアプリはブラウザ版をホーム画面追加しやすいようにしてあります。

- `manifest.webmanifest` を配信
- `appleWebApp` / `themeColor` を設定
- `ホーム画面に追加` ボタンを対応ブラウザで表示

オフライン対応までは入れていません。主目的はスマホからアプリっぽく開きやすくすることです。

### 底値帖と画面の配色

- PC のメニューバーとスマホの下部メニューの「入力」の右隣に「底値帖」を表示します。
- 「底値帖」はアプリ内の `/price-notes` を開きます。家計簿と同じログインで利用できます。
- 商品名・カテゴリ・単位で商品をまとめ、購入店、税込価格、送料、内容量、購入日を PostgreSQL に保存します。
- 内容量と送料は任意入力です。空欄の内容量は未入力として保存し、送料は0円として扱います。任意の入力欄には `(任意)` を表示します。
- 商品のすべての記録に内容量がある場合は、送料込みの単価で比較します。内容量未入力の記録を含む場合は、送料込みの価格で比較します。内容量が空欄のときは、内容量や単価の表示自体を省きます。kg／g、L／mlは自動換算します。異なる単位（個とgなど）は別商品として扱います。
- 検索、カテゴリ絞り込み、並べ替え、履歴の表示・追加・編集・削除に対応します。底値帖は10件ずつ表示し、検索・カテゴリ・並び順の変更時は先頭ページに戻ります。購入先の区分は入力・表示しません。食品・日用品タブでは各行のカテゴリ名を省きます。履歴の削除はゴミ箱アイコン、編集はその左の鉛筆アイコンから行います。商品名・カテゴリ・内容量・単位・お店・価格・送料・購入日を変更できます。実データは空から始まり、以前のデモサイトのブラウザ保存データは自動移行しません。
- スマホのメニュー文字は省略せず折り返して表示します。デスクトップメニューは横幅が十分な1,024px以上で表示します。

#### 底値帖のデータベース

`PriceProduct` と `PriceRecord` の2テーブルを追加します。既存の家計簿テーブル・レコードは変更しません。

```bash
npm run db:price-notes
```

このコマンドは新規テーブルとインデックスだけを作る再実行可能なSQLです。`DATABASE_URL` が必要です。Vercel本番ビルド（`VERCEL_ENV=production`）では同じSQLを自動実行し、失敗時はデプロイを停止します。ローカルやプレビュー用DBでは上記コマンドを先に実行してください。内容量をNULLで保存できるようにするマイグレーションも適用します。既存の内容量は保持します。通常のPrismaマイグレーション用にも同じSQLを `prisma/migrations/20261112000000_add_price_notes/` に含めています。
- 全画面の基本配色は深い青、青みのある明るい背景、白いカードです。カテゴリの選択肢や一覧・凡例には、緑・青・黄土・紫・赤茶などを区別できる落ち着いた色を使います。家族全員と自分のタブは同じ選択色です。彩度を一律に下げず、プラスの金額・収入・収支がプラスの棒グラフは落ち着いた緑系、支出は赤茶系で表示します。アカウントの保存済み色データは保持します。

### 取込・入力

- CSV 取込: PayPay、PayPayカード、楽天カード、三菱UFJ銀行、三井住友銀行
- 直接入力: 支出 / 収入の切替、レシートOCR、カテゴリ選択
- カテゴリマッピング: 店舗名ルールの追加、削除、既存取引への再適用

### キャッシュフロー

ダッシュボードの右隣の `/cash-flow` は、今後の見通しグラフとシミュレーション用ルールだけを表示します。基本設定・ルールは家族共有でDBに保存し、家計簿の取引自体は追加・変更しません。

- 開始年齢・終了年齢・現在の現預金を設定します。基本設定で積立ルールごとの現在の投資残高と、その他の非現金資産を手入力でき、グラフは即座に再計算します。保存すると次回も残高を復元します。積立ルールの残高は同じ値を編集し二重計上しません。その他の非現金資産は利回りなし・残高一定とし、既存の保存JSONでは0円に補完します。基本収支は家族全員の過去実績の月平均、または手入力の月額を使います。実績なしの場合は0円と表示します。
- 給料・保険料・教育費・住宅購入・車購入・ローン返済・生活費・年金・積立NISA・旅行のテンプレートを用意しています。定期収支は月額または年額と年齢区分で設定します。月額は年12回として計算し、給料は手取り額で設定してください。住宅・車は支出のみを計算し、ローン利用時は頭金・諸費用と返済ルールを分けます。資産価値・借入残高は自動計算しません。基本収支に含まれる費用を追加する場合は重複を避けて調整します。
- 年齢別ルール: 教育費等を0〜5歳、6歳以降などの年額で設定します。本人の年齢だけでなく、子ども等の開始年齢をルールごとに指定できるので、複数人を別ルールで扱えます。同一ルールの年齢区分の重複は拒否します。
- 積立・NISA: 開始運用資産、月末の積立、積立年齢の範囲、想定年率を設定します。年率を月利に換算して複利計算し、積立終了後も運用を続けます。積立は現預金から運用資産への移動として扱い、二重に支出計上しません。税・手数料・制度上の上限はモデルに含めません。
- 単発の支出: 本人または指定対象が何歳の年に旅行等へいくら使うかを設定します。
- グラフは開始時と、開始年齢から終了年齢までの各年齢の1年間を反映した概算です。ルールの収入・支出は基本収支に加算します。資金不足は現預金がマイナスの点として表示し、自動売却や借入利息の計算は行いません。
- `CashFlowPlan` テーブルの家族共有JSONに保存します。本番ビルドと `npm run db:price-notes` は追加の冪等マイグレーションも適用します。家計簿データから算出した平均収支は再読込で更新します。

### OCR

`/api/ocr` は Google Cloud Vision を使います。`GOOGLE_VISION_API_KEY` 未設定時は `503` を返します。

- カメラ画像はブラウザで向き・サイズを読み込み、最大4メガピクセル・長辺2,800px・2MiB以下のJPEGに変換してから送信します。大きな写真をそのまま送ることによるホスティング側の容量エラーを避けます。
- 画像の変換に対応できない形式はJPEG/PNGでの再選択を案内します。通信失敗や読み取り失敗でもボタンと写真入力を戻し、同じ写真で再試行できます。
- APIはファイル、容量、形式を検証し、Google応答内のエラー、空の認識結果、利用上限、認証・利用設定、タイムアウトを区別します。Googleの詳細メッセージはそのままブラウザへ返しません。
- 実際の認識には、Google Cloud側でVision APIの有効化・APIキーの権限・割り当て設定が必要です。

キャッシュフローの基本設定は初期状態で閉じたトグルです。グラフの大きな金額は億・兆・万で表示します。設定・ルール・残高は家族共有の1件を保存し、競合時は最後のDB書き込みが優先されます（自動マージなし）。未保存の変更やルール編集中は上書きを避け、通常は15秒ごと・画面復帰時に他端末の保存内容を取得します。

設定の「CSV取込の除外名称」で、PayPay / PayPayカード / 楽天カード / セゾンカード / 三菱UFJ銀行 / 三井住友銀行ごとにトグルを開いて名称を登録・削除できます。正規化した部分一致で今後のCSV取り込みのみをスキップします。同じ名称を別の取り込み元にも登録でき、各一覧は10件ずつ表示します。既存の共通除外名称はマイグレーションで6つの取り込み元へコピーし、これまでの除外動作を維持します。

キャッシュフローの見通しグラフは「全期間」と「1年ずつ」を切り替えられます。1年ずつでは年齢スライダー、左右ボタン、横スワイプで移動し、年初・年末の資産と年間増減を表示します。年単位のモデルの2点を結んだ表示で、月別の実績や予測を新たに生成するものではありません。表示切替は保存データを変更しません。
